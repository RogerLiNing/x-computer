# 第一阶段安全边界修复

本轮范围：HTTP 登录身份、WebSocket 认证与按用户推送、文件路径越界、工作流服务认证、容器初始化失败时拒绝降级。其他审计条目尚未全部修复，不能据此宣称已完成公网或儿童独立使用的安全验收。

## 登录与客户端迁移

登录和注册校验成功后，服务端生成高强度随机会话，仅将令牌摘要和到期时间保存到用户配置的保留命名空间。浏览器使用 HttpOnly、SameSite=Strict Cookie；生产环境启用 Secure，必须通过 HTTPS 访问。普通用户配置接口不暴露或允许编辑会话命名空间。

旧 `X-User-Id`、query.userId 及小程序 URL 中的用户编号不再是登录凭证。携带身份提示时必须与服务端会话一致。升级后旧浏览器需要重新登录，原用户账号、任务和工作区不迁移、不合并、不回滚。切换账号会撤销当前浏览器原会话；退出会撤销服务端记录并关闭对应实时连接。

SDK 登录/注册后保留其独立会话 Cookie；仅调用 setUserId 不会获得授权。浏览器应通过同源反向代理访问 API 和 WebSocket。OAuth 回调在身份验证成功后也会签发会话。

## 实时连接

WebSocket 使用握手 Cookie 验证会话、限制浏览器来源，仅向任务所有者发送任务和审计事件。暂停操作校验任务归属。编辑器流按用户发送，整机上下文按用户保存。退出或到期关闭连接，未知归属数据不作全局广播。

测试用监听器复用生产实时连接实现；新增测试覆盖未登录拒绝、跨用户事件与控制隔离、退出撤销。

## 工作流

主服务和 workflow-engine 必须设置相同的 `WORKFLOW_SERVICE_TOKEN`，至少 32 个字符，作为服务间凭证；不要传给前端或模型。未配置时执行失败，不接受仅凭用户编号的回调。主服务调用引擎、引擎 API、引擎回调主服务均验证服务认证。

工作流脚本复用 UserSandboxManager 提供的执行器，因此启用容器时不会另开宿主 Shell。要求容器隔离但初始化失败时停止启动，不回退到直接模式。

## 文件边界与运行限制

文件接口检查完整目录边界和符号链接的实际目标，拒绝兄弟同前缀目录、外部及悬空链接；保留合法内部链接的重命名语义。用户及智能体目录编号进行格式检查。

这些路径检查不等于操作系统进程隔离。显式关闭容器的直接执行仍只适合可信本地开发；生产需要启用隔离。真实 Docker、OAuth 提供商、跨平台以及并发修改符号链接的对抗验收仍须单独验证。

原 MySQL 的误连历史记录本轮不作回滚、删除或修改。验证使用独立临时 SQLite、模拟凭证、真实本地 HTTP/WebSocket 与临时哨兵文件，不调用真实模型或发送外部消息。


## 2026-10-31 配置与运行凭据边界

用户配置接口不再合并整份服务器默认配置。服务器 OAuth、SMTP、容器、数据库、MCP 环境变量等配置不从用户设置读取或写入；未知的服务器默认项也不会自动进入响应。用户自己的普通偏好和渠道配置保持按账号隔离。模型配置只返回提供商标识、名称、可公开的端点、模型选择与 apiKeyConfigured，不返回模型密钥；带 URL 认证或查询参数的端点也不返回浏览器。

单项和批量模型配置写入共用合并逻辑：GET 缺省的密钥保留在服务端，用户明确提交新密钥时才替换，提交空字符串时清除该用户的密钥。仍保留原有自定义模型配置资格，没有改动套餐。桌面启动只调用统一配置应用函数，不再重复缓存密钥或将配置状态误改为未配置。

MCP 配置页只编辑用户自己的数据库配置或工作区文件；平台继承配置只提示可用性，服务器命令、环境变量、请求头和带凭据 URL 不回显。状态及保存回执只包含服务器名称、工具数及通用故障提示，不回传底层命令或错误中的凭据。用户主动配置的私有扩展仍可查看自己的配置。此变更不等于完成了不可信 MCP 命令执行的容器隔离。

旧 createAndRun Task 的新写入记录仅保存模型选择；执行和恢复时重新查找服务端凭据。加载旧记录时不将其中的模型密钥放进公开内存 Task；未执行历史数据清理，不声称旧数据库或浏览器历史缓存已移除密钥。WebSocket 任务及审计消息进一步过滤 api_key、client_secret、refresh_token、Cookie、SMTP pass 等字段变体。

真实验收使用独立 SQLite、原有专用验收账号及真实平台模型。配置响应中已检查的真实服务器凭据均不存在，界面能显示模型已配置，真实任务 915a0243780ed44ae87f887322d7f688 回复“好”，没有工具或文件副作用。证据位于 outputs/x-computer-config-boundary-20261031/live-api.json 和 real-model.png。验收还修复了悬浮数字人遮挡最大化应用发送按钮的问题；窗口最大化时不再覆盖应用控件。

该阶段之后，MCP stdio/测试入口的宿主执行隔离已补齐，具体边界及证据见 MCP_USER_CONTAINERS.md。仍待完成模型导入等 HTTP 出口约束、容器桥接出口、恶意扩展资源公平性、生成应用 iframe 隔离和统一高风险确认。历史曾回显凭据的环境需要单独评估并轮换密钥；本轮未连接或清理原 MySQL，未修改记忆管理，不构成公开上线或儿童独立使用安全验收。


## 2026-10-31 生成内容与模型导入

生成应用与 HTML/JSX 消息不再共享主界面的执行上下文。自己的资源、存档、键值和队列使用绑定原会话的预览凭证，可信查看器约束应用导航；公开令牌不包含私有存档。浏览器实际验证权限拒绝、导航接收端零请求、计数恢复与同步，真实基础模型任务已确认验收。模型列表导入对用户地址施加公网校验及重定向限制，并把服务端凭据绑定到所选提供商。细节、证据和未完成边界见 GENERATED_APP_SANDBOX.md。

这不等于完成所有浏览器网络协议、其他 HTTP 工具、应用修订与恢复、多实例通知、资源压力或公开发布验收。旧共享浏览器数据未删除，原 MySQL 未改动，记忆管理没有变更。
