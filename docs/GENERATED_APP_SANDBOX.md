# 生成应用与交互内容的预览边界

生成应用、HTML 消息及 JSX 消息均在不带 allow-same-origin 的预览中运行。HTML 不插入主界面 DOM，JSX 在服务端只编译、不执行；React 运行库复用项目已安装依赖，代码只在预览内执行，不再向主界面加载远程 Babel 或执行模型函数。

可信外层页面限定内层应用的 frame-src，应用不能自行导航到其他站点。预览响应本身也包含 CSP sandbox，直接打开内部预览链接会进入可信查看器；旧静态入口同样施加 sandbox。浏览器实测的主界面访问、账户接口和其他应用数据访问均被拒绝，测试导航接收端请求数为零。CSP 和 iframe 不是完整操作系统隔离或所有浏览器网络协议的安全证明。

## 应用资源与登录

登录用户创建预览后获得短期凭证，只能访问本次预览。服务端只存摘要，凭证绑定原登录会话及应用；退出、撤销、到期后不能继续读取资源或调用数据接口。只读资源不需要把账户 Cookie 或模型密钥交给应用。资源必须位于自己的应用目录，拒绝跨目录、符号链接、大小写冲突及超过限制的文件。预览链接不会作为 Referer 发送。

本地 CSS、JavaScript、字体、图片和媒体按应用资源路径加载；应用无账户配置、其他应用、发布令牌、全局文件或任意 HTTP 代理权限。未经授权的外部 CDN 和资源不能依赖预览自动加载，应存为本地资源或另行设计明确的联网授权。

## 存档与数据

常用 localStorage 方法映射到按账号、应用划分的私有存档，不读取主界面共享浏览器存储。写入等到服务端回执后返回，失败时不会假装保存成功。每个值有大小限制，存档名称数量也有限。sessionStorage 为当前预览的内存数据。存档经现有应用频道同步并生成 StorageEvent，当前窗口不重复接收自己的更新；已过期预览不再接收频道数据。

存档使用不可作为应用编号的内部命名空间及摘要键，避免 MySQL 默认排序规则混淆大小写。普通应用公开读取令牌不包含私有存档；早期开发版留下的存档键也不从公开读取入口返回，没有删除旧数据。

应用原有 fetch('/api/x-apps/backend/kv/...') 和队列调用会转到自己的数据通道；传入不同 appId 不能取得另一应用权限。明确持有公开只读令牌时可读取该令牌指定的数据，不能扩大为写权限或创建新的发布令牌。应用自己的键值与队列均有边界检查。

开发时 Vite 默认不接受 null 来源的预检，因此仅为带预览凭证的 __runtime 路径处理所需预检，不放开账户接口。生产代理需转发该路径及预检到后端，不应把开发配置当作完整发布方案。

## 交付与恢复

x.create_app 等待登记写入完成后才回报成功。执行记录中的创建回执会刷新桌面应用列表；验收卡可直接打开记录中的应用，文件或编号失效时明确报错。基础账号可创建、列出应用和查看应用日志，没有修改套餐价格。

应用窗口提供重新打开入口，按最新存档恢复。交互显示方式对普通账号可用；默认仍为文字，生成中的内容不反复编译为交互页面。

应用交付现在把源码和本地资源保存为数据库版本；快速模式更新前另保留原源码，相同内容和名称不重复保存。窗口的“以前的版本”可将旧版本恢复为独立应用，刷新桌面后直接打开。恢复不覆盖当前源码、不回滚或复制业务数据；副本从独立存档开始。源码中原应用编号的数据请求映射到副本自己的运行通道，仍不能访问其他应用的数据。再次恢复副本保留这一映射。

版本只覆盖启用后保存的内容，不能找回此前已经覆盖的历史；工程化应用须在每次交付时重新调用 x.create_app 登记。单版本源码与资源合计上限 4 MiB、最多 256 个目录及文件，不包含隐藏文件；缺入口、超限、符号链接或读取期间文件变化均报错。版本保留尚无总量配额，也不提供跨文件原子开发事务。应用列表登记复用数据库执行权串行更新，读取列表不再删除登记。

2026-11-01 的全新独立 SQLite 环境通过真实模型创建、验收退回、修改交付及原版恢复校验；原版可找回，恢复后当前源码及记忆哈希不变。证据为 outputs/x-computer-app-versions-20261101/real-model.json。浏览器操作和其他数据库的本轮验证以对应记录为准。
