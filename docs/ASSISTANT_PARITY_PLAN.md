# X 助手能力对齐与验收清单

目标来自 Roger老师：将昂贵个人助理产品的核心办事能力做进 X，让没有机会购买这些产品的人也能使用。完成标准是实际任务闭环，而不是模仿界面或宣称模型质量相同。本清单保留完整目标，未验收的项不算完成。

## 参考边界

- deepseek-harness：插件装配、工具发现、执行与持久会话。参考本地 ../deepseek-harness/README.md 及 docs/architecture.md，不引入整套运行时替换现有执行器。
- pi：可恢复的代理会话、交互体验、执行过程可见性；参考本地 ../pi/README.md 和 packages/agent。
- open-duet：命名助理、团队委派、电脑接管、外部应用和周期性任务；参考本地 ../open-duet/docs/FEATURES.md。其功能存在引擎及实验状态限制，不把文档宣传当作已经通过的验收。
- OpenBot：隔离浏览器、控制权状态机、快照失效、参数绑定审批、后台工作租约；参考本地 ../OpenBot/agent-computer/src/control.ts、server/src/approvals 和 server/src/work。
- dots、Muse、Claude Duet：用户交办后持续推进、需要人时明确询问、带回成果；公开来源见 ASSISTANT_PRODUCT_DIRECTION.md。
